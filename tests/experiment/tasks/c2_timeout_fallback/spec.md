# C2 超时与降级(spec)

## 任务

两个子任务,父任务带超时等待:慢子任务 400ms 后产出 99,父最多等 100ms →
超时,采用默认值 0;快子任务 50ms 后产出 99,父最多等 2000ms → 取到真值。

## 要求(行为规则,跨语言等价)

- 慢子任务:计算体在子任务中睡 400ms 后产出 99;父任务等待上限 100ms;
  超时后**不取慢子任务结果**,采用默认值 0。
- 快子任务:睡 50ms 后产出 99;父任务等待上限 2000ms;正常取到 99。
- 超时的子任务允许被硬杀/放弃/留在后台(语言机制差异不验收);两条输出行
  必须按上述固定格式。

## 输出(格式逐字固定,恰好两行)

```
slow_child=timeout fallback=0
fast_child=99
```

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

本任务无外部输入;任何 panic/异常/非零退出都判 FAIL。
