# A4 去重统计(spec)

## 任务

输入目录下有若干分块文本文件(`chunk_*.txt`)。程序按块依次处理,合并统计
行出现次数,输出总量/去重统计与出现最多的前 3 行。

## 输入

- argv[1] = 分块目录。目录中参与统计的文件 = 名称匹配 `chunk_*.txt` 的条目,
  按名称字节序(ASCII)升序处理;其余条目忽略。
- 每文件 UTF-8,`\n` 分行(末尾换行产生的空行不计);行内容 = `[a-z0-9-]+`
  (语料保证,如 `evt-alpha-001`)。

## 统计口径

- 全部块合并计数(跨块累计)。
- `total` = 处理的行总数;`unique` = 不同行数;`repeated` = 出现次数 > 1 的
  不同行数。

## 输出

```
total=<n>
unique=<n>
repeated=<n>
top1 <line> <count>
top2 <line> <count>
top3 <line> <count>
```

- Top-3 = 出现次数最多的前 3 行:次数降序;次数并列时按行内容升序
  (字节序)。不同行不足 3 个时只输出实际数量(语料保证 ≥ 3)。
- `top<i>` 与行内容、次数之间均为单个空格。

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

- 参数缺失、目录不可读、文件不可读:stderr 一行以 `error:` 开头,退出码 1,
  stdout 空。
