# B5 嵌套 JSON 路径查询(spec)

## 任务

读入一个 JSON 文档与一组点路径查询,逐段下钻取值,按固定渲染规则输出每条
查询的结果与汇总;取不到 → MISSING。

## 输入

- argv[1] = JSON 文档路径(顶层对象);argv[2] = 查询文件路径,每行一条点路径
  (`\n` 分行,末尾空行不计)。
- 文档数值全为整数(语料保证);字符串值不含引号/反斜杠。

## 路径语义

- 查询按 `.` 切段,从文档根逐段下钻:
  - 段为纯数字且当前值为数组 → 数组下标(0 起;越界 → MISSING);
  - 否则当前值为对象 → 按键取(缺键 → MISSING);
  - 当前值既非数组也非对象,或数字段遇到对象、非数字段遇到数组 → MISSING;
  - 数字段(如 `servers.3`)只对数组当下标,不会当对象键。
- 语料保证段只含小写字母/数字(无引号键、无转义)。

## 值渲染(输出行 `<查询> = <渲染值>`)

- 字符串 → 原样(不加引号);
- 数值 → 整数十进制;
- 布尔 → `true` / `false`;
- 数组/对象 → 紧凑 JSON(无空格);
- 取不到 → `MISSING`。

## 汇总

末行 `found=<取到条数> missing=<MISSING 条数>`。

## 输出示例(演示格式,非真实数据)

文档 `{"a":{"b":[10,20]}}`,查询 `a.b.1` 与 `a.x` →
`a.b.1 = 20`
`a.x = MISSING`
`found=1 missing=1`

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

- 参数少于 2、文件不可读、JSON 解析失败、文档顶层非对象:stderr 一行以
  `error:` 开头,退出码 1,stdout 空。
