# A2 批量改名(spec)

## 任务

把输入目录中的文件按规则改名后写入输出目录(输入目录只读不动),stdout 打印
改名计划;含目标名冲突处理。

## 输入

- argv[1] = 输入目录;argv[2] = 输出目录(验收器保证初始为空)。
- 输入目录中的条目全为文件(语料保证;程序无需处理子目录)。
- 文件名全为 ASCII;程序以**名称字节序(ASCII)升序**处理(先排序再处理,
  保证输出顺序确定)。

## 规则(按序匹配,一条命中即止;目标占用登记跨规则共享,键 = 相对路径)

- **R1** 名称形如 `report_<digits>.txt`(`<digits>` = 1 位以上十进制数字,即
  `^report_[0-9]+\.txt$`)→ 新名 `report-<NN>.txt`,`NN` = 数字串的十进制数值
  按十进制输出,不足 2 位左补 0(≥2 位原样;`007` 按 7 处理得 `07`;数值超出
  64 位整数范围 → 本条不匹配,落入 R3)。
- **R2** 名称以 `.log` 结尾 → 写入输出目录 `logs/` 子目录,文件名不变
  (`logs/` 仅在存在 R2 命中时创建)。
- **R3** 其他 → 不写文件。
- **冲突**:目标相对路径已被更早处理的项占用 → 跳过该文件(不写);
  占用登记以"成功写入的计划项"为准(冲突跳过的项不登记)。

## 输出(按处理顺序,逐行)

- R1 命中:`OK <old> -> <new>`
- R2 命中:`DIR <old> -> logs/<old>`
- R3:`SKIP <name> nomatch`
- 冲突:`SKIP <name> conflict <target>`(`<target>` = 被占用的目标相对路径)
- 输出目录不存在则创建(含 `logs/` 父级)。
- 写文件 = 原文件字节内容不变地写到目标相对路径。

## 验收(三部分全过才 PASS)

1. stdout 与 `expected/expected.txt` 逐字节相等;退出码 0。
2. 输出目录**集合**与 `expected/expected_files.txt` 相等:每个相对路径存在,
   且顶层条目数、`logs/` 条目数与期望一致(防多写)。
3. 内容抽检:输出 `report-01.txt` 内容 == 输入 `report_1.txt` 内容(字节级)。

## 错误行为

- 参数少于 2 个、输入目录不可读、非法参数:stderr 一行以 `error:` 开头,
  退出码 1,stdout 空。
