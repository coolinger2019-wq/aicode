# A3 CSV→JSON 转换(spec)

## 任务

读取 CSV 文件,按固定方言解析,合法行转为 JSON 对象,字段数不符的行 Err 化进
errors 数组,输出单行紧凑 JSON。

## 输入

- argv[1] = CSV 文件路径;UTF-8;`\n` 分行(末尾换行产生的空行不计)。
- 方言(固定,无引号/无转义):逗号逐字节分隔;第 1 行为表头,列数 = 表头字段数
  (`want`);值全为字符串(不做类型转换);空字段 = 空串(合法)。
- 语料保证:值不含引号、反斜杠、逗号、换行(无需转义;实现可用语言内建
  JSON 序列化,输出一致)。

## 规则

- 每个数据行(表头之后):按逗号切分,字段数 == `want` → row 对象;键 = 表头列名
  (按表头顺序),值 = 对应字段字符串。
- 字段数 != `want` → error 对象:`{"line":<行号>,"got":<实际字段数>,"want":<want>}`,
  行号 = 1 起计且**含表头行**。
- 空行(除末尾外)按 1 个字段计(即成为 error 行;语料保证不出现)。

## 输出

- 单行紧凑 JSON(无空格):`{"rows":[<row>,...],"errors":[<error>,...]}`,
  顶层键序固定 `rows` → `errors`;row 键序 = 表头序;error 键序 = line,got,want。
- 例(演示格式,非真实数据):表头 `a,b`,数据 `1,x` / `2,y,z` →
  `{"rows":[{"a":"1","b":"x"}],"errors":[{"line":3,"got":3,"want":2}]}`

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

- 参数缺失或文件不可读:stderr 一行以 `error:` 开头,退出码 1,stdout 空。
