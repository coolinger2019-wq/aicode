# B1 JSON 深合并(spec)

## 任务

读入两个 JSON 对象文档,按"深合并"规则合成一个对象,输出单行紧凑 JSON。

## 输入

- argv[1] = 文档 A 路径;argv[2] = 文档 B 路径;两个顶层都必须是 JSON 对象
  (否则报错退出)。
- 文档为 UTF-8 单行/多行均可(按 JSON 解析);数值全为整数(语料保证);
  字符串值不含引号/反斜杠(无需转义,内建序列化输出一致)。

## 深合并规则

- 两边在同一键上**都是对象** → 递归深合并;
- 其他任何情况(标量/数组/null/一边对象一边非对象/类型不同)→ **取 B**;
- A 独有的键保留(A 的值);B 独有的键追加(B 的值)。
- **键序**:A 的键按 A 中的出现顺序(独有键取 A 值,共有键取合并值),
  然后追加 B 独有键(按 B 中的出现顺序)。递归对象同样适用。

## 输出

- 单行紧凑 JSON(无空格),末尾换行由输出语句自带。
- 演示(非真实数据):A = `{"x":{"p":1},"y":2}`,B = `{"x":{"q":9},"z":true}` →
  `{"x":{"p":1,"q":9},"y":2,"z":true}`

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

- 参数少于 2、文件不可读、JSON 解析失败、顶层非对象:stderr 一行以 `error:`
  开头,退出码 1,stdout 空。
