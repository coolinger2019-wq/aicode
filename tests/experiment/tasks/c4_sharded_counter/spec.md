# C4 竞态防护:分片计数合并(spec)

## 任务

4 个分片**并行**统计各自数据片段的命中数,父任务合并。数据由公式生成;
**禁止**多线程对同一共享计数器裸累加——必须"每分片本地计数 → 父任务合并"
(这正是分片防竞态的设计点)。

## 数据公式(固定)

- 分片 s(s = 1..4),片内 j = 1..16:
  - `v = (s*13 + j*7) % 6`
  - `v == 0` → 该次为命中(记 1);否则不命中。
- 每分片命中数由并行子任务计算并返回;父任务按序合并输出。

## 输出(格式逐字固定)

```
shard1=<分片1命中数>
shard2=<分片2命中数>
shard3=<分片3命中数>
shard4=<分片4命中数>
total=<四片之和>
```

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0;并行形态由执行者
代码审查标记(验收只看输出)。

## 错误行为

本任务无外部输入;任何 panic/异常/非零退出都判 FAIL。
