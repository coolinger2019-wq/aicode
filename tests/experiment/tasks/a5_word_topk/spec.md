# A5 词频 Top-K(spec)

## 任务

读取文本文件,按空白切词,统计词频,输出次数最多的前 5 个词。

## 输入

- argv[1] = 文本文件路径;UTF-8;词 = 空白字符(空格/换行;语料不含制表符)
  切分出的非空片段;大小写敏感;词内容 = `[a-z]+`(语料保证)。

## 规则

- 全文统一计数;K = 5(固定)。
- 排序:次数降序;次数并列时按词升序(字节序)。
- 输出前 5 行 `word count`(单个空格);不同词不足 5 个时只输出实际数量
  (语料保证充足)。

## 输出示例(演示格式,非真实数据)

文件内容 `b a b a c c` → 输出:

```
a 2
b 2
c 2
```

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

- 参数缺失或文件不可读:stderr 一行以 `error:` 开头,退出码 1,stdout 空。
