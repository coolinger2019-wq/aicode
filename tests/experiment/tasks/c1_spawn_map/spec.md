# C1 spawn 并行汇总(spec)

## 任务

4 个分片并行计算,父任务按序合并。分片 i(1..4) 负责区间
`[25*(i-1)+1, 25*i]`(即 1..25 / 26..50 / 51..75 / 76..100),计算区间内全部
整数的**平方和**;父任务输出各分片值与总和。

## 要求

- 分片计算必须在**并行子任务**中完成(spawn/worker 线程/线程),父任务不得
  串行算分片(验收只看输出;并行形态由执行者代码审查标记)。
- 输出按分片序固定(与并行完成顺序无关)。

## 输出(格式逐字固定)

```
shard1=<分片1平方和>
shard2=<分片2平方和>
shard3=<分片3平方和>
shard4=<分片4平方和>
total=<四片之和>
```

参考值(供验收对拍,程序不得硬编码):总平方和 = 1..100 平方和 = 338350。

## 验收

stdout 与 `expected/expected.txt` 逐字节相等,退出码 0。

## 错误行为

本任务无外部输入;任何 panic/异常/非零退出都判 FAIL。
