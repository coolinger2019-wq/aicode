# Ming 支持矩阵(语言形态 × 后端;机器可验证)

> 本表由 `tests/support_matrix/run.mjs` 程序化生成——**每一格都是该后端实际执行一次探针程序得出的判定**;
> 期望值钉死在 harness 的 EXP 表内,harness 逐格比对,期望 ≠ 实际 → exit 1(实现的任何行为漂移都会让矩阵变红)。
> 人只读此文档;矩阵变更必须同步探针与 EXP 表(plan §4.15 T4.3 验收:矩阵与探针 100% 一致)。
>
> **与 GUIDE / capabilities 的关系**:`docs/capabilities.md` 是"能力"粗粒度(55 行,✅/🟡/❌ 三态,42✅ 10🟡 3❌);
> `GUIDE.md` 是用户手册语义说明;**本表是"具体语言形态 × 具体后端执行路径"的细粒度事实表**,只追求诚实,不追求追平。
>
> **判定口径**:
> - ✅ 正常 —— 退出码 0、stdout 与期望逐字一致、stderr 为空;
> - ⛔ 具名拒绝 —— 编译/检查期拒绝(退出码 1),首行诊断含表中码与原因(检查器 M 码、C1 资格拒绝、build 失败诊断);
> - ☠️ panic —— 运行时 panic(退出码 101),stderr 首行含表中 M 码与消息;
> - ↩️ 前缀(仅 AOT 列)—— `ming build` 对该形态具名回退源码模式(dist 无字节码;stderr 有"AOT 不可用"提示,非静默),dist 实际运行结果如实展示;
> - 统计口径:↩️ 为 ✅ 的子集(回退格同时计入 ✅),格数相加 > 总格数;探针 13(asm)使用 bswap 指令(x86-64)——CI runner 非该架构时该格如实报红;
> - – 跳过 —— cc 列无编译器时整列跳过(AOT 列当前无跳过形态)。
>
> 每格只标最短原因;逐形态完整说明(含 cc 拒绝原文与 AOT 回退口径)见表格下方的"逐形态说明"。探针源程序见 `tests/support_matrix/run.mjs` 的 PROBES 表。

## 逐形态说明

- **01 整数 BIN 溢出(i32 后缀)** —— 窄型后缀算术溢出;cc 资格拒绝(i32 绑定 let 推导 null),AOT 字节码 M4002
- **02 整数 BIN 溢出(u64 后缀)** —— u64 fits 门四引擎一致;cc 真实执行也 panic M4002(C 侧同模板)
- **03 BIND 归一窄型溢出(i32 槽)** —— 绑定归一 panic 位置 = 绑定名 token(v0.90 3:9 统一);cc 资格拒绝
- **04 无后缀字面量超 i64 进 u64 槽** —— 2^63 与 u64max 无后缀字面量绑定 u64 槽;五列全通过
- **05 tree ctor 作值(held ctor 调用)** —— let c = E.A; c(250) + Option.Some 部分构造器(v0.90 tree 对齐 VM)
- **06 struct 跨构造点相等** —— #73:v0.90 起异构造点同类型 struct 值相等判定正确(AOT 含)
- **07 enum 跨构造点相等** —— #73 同族:enum 同构造 true / 不同载荷 false / 无载荷变体 true
- **08 元组模式绑定归一** —— let (a, b) = (1, 2) + 窄型注解 (u8, u8);cc 拒绝元组 let 形式
- **09 闭包捕获调用** —— lambda 捕获外层局部并调用(形参需类型标注,推断缺失 M3003);cc 不支持闭包;AOT 具名回退源码(闭包缺签名)
- **10 本地函数递归** —— 块级 fn 自递归(v0.59 #44 恢复);cc 不支持本地函数(C1 语句 FnStmt)
- **11 match 守卫臂** —— Rust 风格 `模式 if 条件 => 值`;cc 仅整数字面量臂(C1)
- **12 unsafe 块(Ptr 内存读写)** —— tree/VM M4016 具名拒绝;cc 真实执行(alloc/store/load/free);AOT 回退源码后同 M4016
- **13 asm 块(bswap 确定性形态)** —— tree/VM M4017 具名回落;cc 经 __asm__ volatile 真实执行;AOT 回退源码后同 M4017
- **14 eval builtin(运行时编译执行)** —— with eval 门禁;内层恒 tree;cc 发射期拒绝;AOT 具名回退源码后可用(输出末尾多一空行 = 外层 print 补的换行)
- **15 spawn/join(结构化并发)** —— worker 隔离 + join Result;sync 形态 AOT 具名回退源码后可用
- **16 窄型算术 fits 门(i8 溢出)** —— v0.85 fits 门:127i8+1i8 运行时 M4002(非静默回绕);cc 拒绝窄型打印
- **17 污点 sink M3049(污进净槽)** —— Untrusted[str] 直传净 str 槽 → 检查期 M3049;五列同拒(check 先于引擎)
- **18 Slice 视图逃逸 M3051** —— Slice[u8] 块内线性:跨函数返回视图 → 编译期 M3051;五列同拒
- **19 read_bytes_range(最小流式范围读)** —— v0.86 S1:范围读 + 短读合法(读 2 字节);AOT 真字节码可用
- **20 字符串插值** —— 数值段插值;cc 不支持插值串(C1, GUIDE C 面已声明)
- **21 泛型 impl 方法(ToStr)** —— 泛型 struct + bound trait impl;泛型形态 AOT 具名回退源码后可用
