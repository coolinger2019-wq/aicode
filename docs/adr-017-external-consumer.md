# ADR-017: 外部消费者认定标准与首个外部消费者（ming-proof-consumer）

> **状态**:**已裁决 go（架构师，2026-11-28，维护者指令）**——三条认定标准钉死；首个外部消费者由团队主动构建（性质外部的独立仓库 ming-proof-consumer：独立证明复核器）；据此 **roadmap §6 P1 准入条件达成**。
> **来源**：维护者指令（2026-11-28）："把门槛从被动等待改成主动造第一个过桥的人……这不是造数据，是先造桥、再造第一个过桥的人"。
> **关联**：roadmap.md §6（仓库根,维护者原稿,已随 §4.21 入库;去转义注册本 = docs/roadmap-infrastructure.md——P1 准入 = 证明协议稳定 + 至少一个外部消费者）、docs/proof-protocol.md（工件协议）、examples/consumers/verify_cert.py（在库消费套件——按本 ADR 口径**不算**外部消费者）、plan §4.26（消费者门槛 = 0 的判定）。

---

## 1. 认定标准（三条件，缺一即不算）

| # | 标准 | 判定方法 |
|---|---|---|
| C1 | **消费方代码独立于 Ming 仓库** | 消费方为独立 git 仓库（不在 aicode 树内；无路径依赖、无 `import` Ming 源码） |
| C2 | **消费方不依赖 Ming 工具链即可运行** | 断言：在仅含消费方仓库 + Python + Z3 的环境里完整跑通（Ming 仓库缺席/不可达）；产物输入为纯数据文件 |
| C3 | **消费的是证明工件或契约工件，不是调用 Ming 运行时** | 消费对象 = `check --proof-report` JSON、`--proof-format smt-lib` 脚本、`.mingi` 桩、证书/manifest 等**导出工件**；运行期不 invoke `node bin/ming.js` |

按此口径，**在库的既有面全部不算**：tests/z3_check.mjs（在库、CI 内）、examples/consumers/verify_cert.py（在库）——它们是消费套件/参考实现，不是外部消费者。§4.26 的"消费者 = 0"判定与本节口径一致，非自我否定。

## 2. 首个外部消费者 = ming-proof-consumer（独立证明复核器）

**定位**：维护者最小可行路径第 1 项——不依赖任何未兑现项，只吃已全兑现的 P0 工件；把"可独立复核"从叙事变成外部可运行的事实。

- **仓库**：`C:\code\ming-proof-consumer\`（独立 git 仓库；不设远程、不推送——存在性即满足 C1；后续若发布到第三方平台则升级为真第三方采用，另行登记）。
- **输入**（纯工件，C3）：`--proof-report` 的 JSON（义务表 + 判定声明）+ `--proof-format smt-lib` 的 `.smt2` 脚本（块内嵌判定声明注释）；manifest v2 可选校验（`artifacts` 哈希 ↔ 脚本字节一致性）。
- **协议**（proof-protocol §6.2 独立重演）：逐方向块用 Z3 重解——`proven ⇒ unsat` 硬判定；`violated ⇒ sat`（除非假设集自身 unsat = 规则 4 豁免，消费者自行剥 goal 断言二解）；`unknown` 三值化——**不是通过**（对齐"求解器超时 11 条与全部 discharged 打同一行即协议失败"的立场）；`unproven` 块无声明可核 → 跳过但计数（诚实覆盖面）。
- **实现**：Python ≥ 3.8 纯标准库 + Z3（`z3` 二进制优先，`z3-solver` pip 包兜底）；退出码 0 全验证 / 1 任何错配 / 2 用法错。
- **证据运行**：以 Ming 生成三形态语料工件（proven / violated / loop 循环义务），拷贝至消费者仓库 `examples/`（纯数据），在**不含 Ming 仓库的目录**运行 → 全验证 exit 0。该运行记录 = "首个外部消费者"的硬证据（判定记录见 plan §4.27）。

## 3. 门槛裁决与诚实边界

1. **roadmap §6 P1 准入达成**：P0 稳定（§4.23 确认）+ 外部消费者存在（本 ADR §2，三条件逐条满足）。6.1（Agent 原生协议）/ 6.2（参数化效果）由 ⛔不可做 转为 **可排期**——是否启动、何时启动仍由维护者逐批裁决，本 ADR 不自动开工。
2. **诚实边界（不预支叙事）**：自建外部消费者 = **桥head/第一个过桥的人**，不是第三方采用。任何文档/帖子不得表述为"已有第三方采用"；准确表述 = "首个外部消费者已由团队按三条标准构建并运行，第三方采用仍为 0"。
3. **复核不对称性如实**：该消费者由团队编写，其与 Ming 判定的独立性是**实现独立**（不同语言/不同求解器驱动/不同代码库），非组织独立——若 Ming 判定器与消费者有相同的概念性错误，两者可能同判。此为已知边界，第三方消费者出现时自然消除。
