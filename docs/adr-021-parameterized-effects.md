## 1. 语法（additive,向后兼容 100%）

- 效果声明混用形态:`with io, fs("/data/**")`——带参效果与裸名效果自由混列（parser §1 既有 with 列表扩展）。
- **裸 `fs`（无参数）语义不变 = 无界授权**——既有全部代码逐字节不变（零破坏锚）。
- **MVP 仅 `fs` 带参**;`net`/`exec` 带参 → 解析层具名拒绝（登记候选,不静默）。

## 2. 授权模式文法（确定性,无 glob 引擎）

三形态（其余形态解析层具名拒绝）:
- **精确文件**:`fs("/data/x.csv")` — 只授该路径本身;
- **目录前缀**:`fs("/data/")` — 授 `/data/` 下全部(含子目录,前缀 + 分隔符语义);
- **显式通配尾**:`fs("/data/**")` — ≡ 目录前缀(显式写法);`fs("/data/*")` — 授直接子项(不含更深)。
- 路径匹配 = 逐字符前缀比较(规范化:两端匹配前对授权模式与请求路径各自按字面处理,**不做 `..`/符号链接解析**——与 sanitize_path 的既有分工如实登记:`..` 逃逸由 sanitize_path 处理,效果授权按字面路径匹配);中段 `*` 不支持(具名拒绝)。

## 3. 静态包含关系（新码 M3055[fs-effect-param-containment]）

调用方声明 fs(P) 可调用被调方声明 fs(Q) ⟺ ∀q∈Q ∃p∈P: p 覆盖 q（覆盖 = 精确相等,或 p 为目录前缀且 q 落于其下）。特殊规则:
- **调用方裸 fs = 覆盖一切**（含参数化被调方）——向后兼容根;
- **被调方裸 fs = 无界要求** → 参数化调用方**不可调**（授予子集无法证明覆盖无界）→ M3055(静态 error;span = 调用表达式);
- 双方均参数化 → 逐模式包含判定;不满足 → M3055(列出不覆盖的被调方模式)。
- 三处登记:src/diag.js + docs/diagnostics.md + tests。

## 4. 运行时强制（新码 M3054[fs-path-denied],tree/VM 单点）

- **根授权** = main/顶层 with fs 参数集;裸 fs 根 = 无界(现行为)。
- 调用时帧携带授权集(子帧 = 父帧授权 ∩ 调用点静态蕴含的子集——MVP 简化:**子帧授权 = 被调方声明集**;调用点已被 M3055 静态证明覆盖,运行时以被调方声明集为活跃集即安全)。
- **强制点 = interp.js fs switch 入口**(read/write/list/make/exists/metadata/delete 全部):解析路径 ∈ 活跃集?否 → **M3054 具名 panic,exit 101**(与 M4016/M4017 同族——违反自身声明的效果边界);裸 fs 帧零检查零开销。
- **核心价值**:静态包含关系只能证"声明覆盖声明";**动态路径**(`fs.read_file(user_input)` 路径运行时才知)只有运行时强制能拦——这正是 roadmap "Agent 生成的代码只能访问指定路径" 的兑现点。
- 诊断对象含:请求路径、活跃授权模式、当前 fn。
