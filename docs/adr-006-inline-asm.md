## 1. 语法(钉死 grammar——parser/checker/测试共同依据)

```
asm 块(仅语句位;函数须声明 with asm):
  asm {
      <模板字符串字面量>+                    // 1+ 个 str 字面量,逐字拼接为 GCC 扩展 asm 模板
      (out ( <约束字符串字面量> , mut <i64 变量> ))*   // 0+;asm 写入该变量(GCC "=..." 约束)
      (in  ( <约束字符串字面量> , <i64 表达式> ))*     // 0+;值经 gcc 约束机制传入
      (clobber ( <字符串字面量> )+)?                   // 可选;被破坏寄存器列表
  }
```
- 模板/约束/clobber **必须字符串字面量**(parser 强制——运行时拼接在解析层拒绝,注入面消除);操作数占位符沿 GCC 约定(%0/%1…,按 out 先 in 后的声明序编号)由用户写在模板里,cbackend 逐字透传。
- 全部操作数 i64(64 位命名口径:RAX/RSP;EAX 等为 32 位别名,模板内由用户按 gcc 语法书写);out 目标必须是 `mut` 局部变量(asm 写入语义,非 mut → M3004 类既有码)。
- asm 块 = 语句、无值;可出现在 `with asm` 函数体内任何语句位(独立门禁块,与 unsafe 块形态同构)。

## 2. 语义与引擎口径

- **cc 路径**:cbackend 发射 `__asm__ volatile( <模板拼接> : <outs> : <ins> : <clobbers> );`——volatile 固定(副作用块);out 变量经 "=..." 约束自动回写。in 操作数按声明序求值。
- **tree/VM/wasm**:执行 asm 块时抛 `Panic('M4017', '内联汇编仅由 C 原生后端(ming cc)执行;tree/VM 不伪装机器语义', span)`——exit 101,消息逐字(M4016 unsafe 先例句式)。
- **资格**:`asm` 不入 wasm effectOk → 含 asm 函数永不 wasm eligible(自动,零改动);C 资格新增 **C6 旗标**(asmEffectsAllowed,仅 cc 路径传入——C5 unsafe 先例);静态证明面排除含 asm 函数(本地函数先例口径)。
- **build/tools**:`with asm` 程序 `ming build` 显式回退源码模式(usesAsm,usesEval/usesUnsafe 同款具名 throw);tools AOT 缓存 probe hasEff 排除。

## 3. 门禁与安全

- 调用方必须 `with asm`(M3029 逐层传播);契约内 asm → M3029(非纯);serve handler 白名单不含 asm → M3002(自动)。
- **注入卫生**:模板/约束/clobber 全部字符串字面量(解析层强制);操作数值走 gcc 约束机制($ 占位符由 gcc 替换),用户模板不与运行时值拼接——**无注入面**。污点面:i64 操作数槽位天然拒绝 Untrusted(无隐式转换)。
- asm 是语言最大逃逸舱口——签名可见性是唯一防线(效果签名 + 具名回落 + build 回退全部强制),不承诺"汇编代码无害"(与 unsafe 同款诚实口径)。

## 4. 诊断码

- **M4017[asm-cc-only]**(error,panic 101):非 cc 引擎执行 asm 块。M4017 号段曾于 v0.64 作 FFI 架构提案、经安全实测否决**存档且从未发布**——复用登记(号段无已发布码冲突)。三处登记:diag.js CODES+CODE_HINTS / docs/diagnostics.md / 测试。

## 5. 范围边界(v1 明确不做)

可执行内存分配与跳转执行(mmap+exec——shellcode 嵌入前提);运行期 gadget 组链(ROP——依赖二进制布局/ASLR,编译期内联 asm 不服务);asm 块内跳转出块/长跳转;多架构模板(本后端 x86-64 gcc 单架构);asm 作表达式/有值形态。

## 6. fuzz 与差分合同

模糊器不生成 `with asm` 程序——asm 语义由专项测试锁定(§77),差分合同 = "cc 侧逐字透传 vs 其余侧具名拒绝"(unsafe 单后端先例口径,如实登记)。

## 8. 结论

**做——`with asm` + 类型化操作数 + cc 独占 + M4017 具名回落 + build 回退;实现 = v0.74,测试 §77(10–15 条)。** 一句话:与 eval 同方向——asm 不是逃逸舱口而是第 13 个门禁面(签名可见、引擎具名回落、build 回退、注入面在解析层闭合),唯一放进来的是"维护者明确要求的寄存器级进出口"。
