## 1. 摘要

| 假设/指标 | 判定 | 一句话依据（计算式见 §4/§5/§3） |
|------|------|------|
| **H1 首次通过率** | **不确定** | ming 100%（42/42）vs ts 97.62%（41/42）vs py 100%（42/42）；ming 相对 ts 仅 +2.4%（=1/41），相对 py 0%——均 ≤20% 阈值；方向一致（ming 不劣于任一对照）故也非"不支持" |
| **H2 修复轮次** | **不确定** | 修复轮/run：ming 0、py 0、ts 0.048（2/42）；ming vs py 两值均 0 → 零分母条款"只记绝对差并标不确定"；ming vs ts 同条款（min=0）；轮号口径（1.000/1.048/1.000）相对差 4.8% 亦 ≤20% |
| M2 缺陷数（辅助） | 不可判（方向有利） | ming/py 全 0；ts 共 9（静态 8 + 验收失败腿 1），per-run 9/42=0.214；零分母条款 → "不确定" |
| M4 token（辅助） | 方向不利、低置信 | 估算值 ming 1586 / ts 1283 / py 976 token/run；ming 高于 ts 23.6%、高于 py 62.5%——形式上越过 20%，但自报估算口径缺陷（偏差 4）+ 提示节长度差使其只作登记、不作宣称 |
| M5 墙钟（辅助） | 未采集 | wall_ms 全 null（偏差 2）——永久缺口 |

**核心结论**：两项预注册假设均判"不确定"。这主要是**区分度不足**的证据，而非"无差异"的证据：三语言首过率被压在 97.6%–100% 区间（天花板效应），预注册 20% 相对差阈值在近满分样本上无区分力——单次 run 失败（1/42）在分母 42 下最多贡献 2.4% 相对差。全部 126 个 run 中仅 2 个 run 出现修复轮、仅 1 个 run 首过失败（a3-ts-r2，验收输出 `FAIL stdout mismatch actual_len=237 expected_len=238`，1 字节之差）；无 failed 格、无 env_blocked 格，126/126 最终通过。

**读报告须知**：H1/H2 判"不确定"不等于"Ming 与对照无差异"，只等于"在本实验的样本量与预注册阈值下，数据不足以支持 >20% 优势的宣称"（§4 第 6 步、§6.1 第 3 条）。

## 4. H1 判定推理（首次通过率）

**预注册判据**（设计 §3）逐条款对照：

| # | 判据条款 | 本数据读数 | 结果 |
|---|------|------|------|
| 1 | 支持：Ming 相对差 >20% 优于 ts | (100−97.62)/97.62 = 1/41 = **2.44%** | 不满足 |
| 2 | 支持：Ming 相对差 >20% 优于 py | 0% | 不满足 |
| 3 | 支持：方向一致 | ming ≥ 两对照于 14/14 格（13 格三语言并列满分，仅 a3 格 ming 3/3 > ts 2/3） | 满足 |
| 4 | 不支持：Ming 劣于任一对照 >20% | 无任何反向格 | 不成立 |
| 5 | 样本不足条款：任一两值相对差 ≤20% | 条款 1/2 均触发 | → 不确定 |
| 6 | 任务级方向一致性检验 | 无反向任务（条款 3） | 不另触发 |

**结论：H1 = 不确定**（条款 1、2 未达阈值；方向虽一致，不构成"支持"）。

补充读法：本样本对 H1 的检验力受天花板效应压制——ts 唯一一次首过失败（a3-ts-r2）仅 1 字节 stdout 失配，若该 run 通过则三语言完全并列、相对差归零。即 H1 的"不确定"对单 run 采样噪声敏感，2.4% 与 0% 的差别不构成 Ming 优势的可靠信号；反之，也不构成"Ming 无优势"的证据。

## 5. H2 判定推理（修复轮次）

**读数（三种口径，判定不变）**：

| 口径 | ming | ts | py | 说明 |
|------|------|-----|-----|------|
| 修复轮数/run（M3 设计定义） | 0.000 | 0.048（2/42） | 0.000 | a3-ts-r2（验收 FAIL→修复）+ b2-ts-r2（自发修复，见下） |
| 平均通过轮号/run（matrix avg_rounds 语言级） | 1.000 | 1.048（44/42） | 1.000 | 与 matrix.json 逐格一致（a3-ts=1.3、b2-ts=1.3，余 1.0） |
| 严格口径（剔除 b2-ts-r2 自发轮） | 0.000 | 0.024（1/42） | 0.000 | 见口径灰区 |

1. **ming vs py**：两值均 0 → 设计 §3 零分母条款"任一值为 0 时只记绝对差并标'不确定'" → 绝对差 0 → **不确定**。
2. **ming vs ts**：min(ming, ts) = 0（ming）→ 同条款 → 绝对差 0.048（严格口径 0.024）→ **不确定**。
3. **轮号口径复核**（防零分母条款规避）：1.000 vs 1.048 → 相对差 = 0.048/1.000 = **4.8%** ≤ 20% → 仍"不确定"。三条路径同判。
4. **"不支持"检验**：ming 修复轮不多于任何对照 → 不成立。
5. **结论：H2 = 不确定**。

**口径灰区（偏差 8）**：b2_validate_pipeline-typescript-r2 的 round-1 verify 已 **PASS**（exit 0），仅 1 条静态错误 TS1259；round-2 是生成者**自发**清除静态残留，非验收触发的修复。预注册 M3 定义为"从首次生成到首次通过验收的修复循环数"——按此定义该 run 的 M3 贡献应为 0；matrix.json 的 avg_rounds=1.3 则计为通过轮号 2。两种口径均远低于 20% 阈值，判定不受影响；但该格 avgRd=1.3 的口径含义与 a3-ts=1.3（真实验收失败触发）不同，引用时须区分。

## 6. 局限

### 6.1 设计 §6 预注册局限（逐条引用，禁止外推）

1. **单机单环境**：win32 + Node 24.11 + Python 3.10.11；结论不跨平台外推。
2. **单模型**：GLM-5.3-Flash 一个快照；不支撑"所有 AI"的宣称。
3. **小样本**：126 run；任务级格子仅 3 run——任务级数字只作线索，不作结论。
4. **任务构造偏差**：任务由 Ming 项目成员设计，可能无意识偏向 Ming 能力面（显式类型/效果系统/确定性）；以 CLI/数据/并发为主，不覆盖 GUI/数值计算/ML。
5. **提示语言**：任务描述为中文；中英文提示表现差异未控制。
6. **硬编码作弊面**：固定输入+固定验收下模型理论上可背输出；已用"输入不进提示"压低，以审查与 grep 复核（§2.5：0 匹配），无法机械杜绝。
7. **B3/B4 harness 单实现**：harness 缺陷三语言风险共担；harness 已经参考实现验证。
8. **Python 版本偏差**：实况 3.10.11 vs plan 原文 3.12——已登记，结论措辞须带此偏差。

### 6.2 采集偏差与数据完整性审查结论（10 条，逐条如实登记）

- **（MAJOR）修复轮覆盖致 round-1 不可复核**：两个修复轮 run（a3-ts-r2、b2-ts-r2）的 round-1 生成物被 round-2 覆盖——work/<run_id>/ 与 .zcode/exp-gen/runs/ 暂存目录均只存终态文件；实际 sha256（`47356983…`/`d94c2071…`）= round-2 行登记值，round-1 行登记 sha（`665f8577…`/`a98fcd28…`）在盘上无对应文件，**round-1 程序内容不可恢复、sha256 不可复核**。指标值不受影响（round-1 的 verify/static 结果已入 JSONL），但可审计性受限。
- **（偏差 1）温度未控**：temperature 全 null（ZCode subagent 默认采样不可设）——c3_budget_degrade 格内 r2/r3 出现近重复实现（审查结论：ming/python 归一化行集相似度 1.00），名义 n=3 存在有效多样性退化。本报告复算（剔除行注释+空白归一后的行集 Jaccard）：c3-ming r2~r3 = **1.000**（与审查吻合；原始行数 27/28，差异全为注释与空行）；c3-python r2~r3 = **0.889**（同一归一化口径下低于 1.00——审查简报所引 0.762 经四口径复算均无法命中、以本报告实测 0.889 为准；r2/r3 仍为同型实现且均一次通过，退化结论不受影响）；全 42 格 ×3 对扫描仅此 2 对为同格近重复（≥0.9 者唯 c3-ming 对）。
- **（偏差 2）M5 永久缺口**：wall_ms 全 null（42/44/42 行复算）→ M5 按"未采集"报告，无任何墙钟结论。
- **（偏差 3）rounds 槽位字段全 null**：轮次可由逐行 round 字段推导，无信息损失。
- **（偏差 4）M4 token 为生成者自报估算且未标注口径**：同一 prompt 跨 run 的 prompt-token 值波动（ming 9/14、ts 10/14、py 9/14 任务内跨重复波动）——M4 全部读数按"估算值"口径给区间（§3.1），不设精确宣称；另 M4 含语言约束节长度差（ming 745 > ts 398 > py 288，单位 = UTF-8 字节，14 个 prompt 实测均值；字符数口径约 506/271/190，排序一致），跨语言可比性进一步受限。
- **（偏差 5）env 指纹 tsc 列**：ming/py 行的 tsc 值为 npx 版本探测噪音（7.0.2），与被测腿无关；ts 行统一 tsenv 5.9.3。
- **（偏差 6）ming_head 采集期三值漂移**：259d744/322c64e/1c8697c，均为 tests/docs 提交，引擎面稳定（ming_version 恒 v0.100.0）；prompt 字符串写 v0.97.0（设计 §8 缺口 9 同源漂移：预注册基线 v0.97.0/HEAD b2c91dc，实采 v0.100.0）。
- **（偏差 7）AGENTS.md 环境上下文**：ZCode subagent 环境自动注入仓库级说明，含 Ming 工具链与惯用法信息（三语言同受注入，但内容偏 Ming）——知识来源不确定性，登记不裁决。
- **（偏差 8）b2×ts-r2 额外修复轮**：round-1 verify 已 PASS、生成者自发修静态残留——抬高该格 avgRd 的口径灰区（§5 已析）。
- **（偏差 9）schema 字段命名**：notes（设计写 note）；program.path 指 work 副本、source_path 指 .zcode/exp-gen 生成暂存（暂存与 work 同被 round-2 覆盖，见 MAJOR）。
- **（偏差 10）采集协议修订史**：两次作废重采——① 生成者越界读 tools/ 与 examples/（tools 含与 a2/b5 同题材实现，污染风险成立；根因=架构师模板漏禁）；② a1-ming-r2 首发模板被误注入 Ming 专属提示（std 全路径/print 换行/污值比较）——均按"违反隔离不入样本"处置（plan §4.18.6.3），协议冻结为 v2.2（唯一输入=裁剪 prompt+record 反馈；语言知识仅来自语言约束节）。数据可见观察：127 行记"协议v2.2"、1 行（a1-ming-r1）记"协议v2"——对应 v2→v2.2 回退发生在首格重采与第二格之间（18:12 vs 18:25Z）；该行生成者隔离经重采报告核验独立（PROTOCOL-LOG：整体覆盖自写、未读禁区），协议字符串未回填，登记不裁决。

### 6.3 格内近重复对 n=3 方差的影响

预注册"每格 3 run"的方差意义依赖重复间独立性。偏差 1 表明温度未控下 c3 格 ming/python 的 r2/r3 有效样本数退化（ming 对归一化行集完全重合）。本实验的三态判定只依赖语言级 42-run 聚合（c3 仅占 1/14 权重），且近重复 run 全部通过、方向与格内其余一致——**不影响本轮三态判定**；但任何任务级/格内方差的后续解读必须先扣除该退化。

## 7. 结论与后续

**结论**：在本任务集（14 个固定工程任务）、本模型（GLM-5.3-Flash）、本环境（win32 / Node 24.11 / Python 3.10.11 / Ming v0.100.0）下，H1 与 H2 均判**不确定**：Ming 首过率 100%、修复轮 0，不劣于两个对照（方向一致），但与 Python 完全并列、与 TypeScript 的相对差（2.4%/4.8%）远低于预注册 20% 阈值。不预支向其他任务集、模型、环境或 Ming 版本的推广。

**对语言工作组的可操作启示（只写数据里看得见的）**：

1. **Ming 静态诊断回路在本样本中零触发**：42 个 ming run 全部 0 错误 0 警告（static_check 逐行复算）——预注册的"静态检查输出回传修复"通道在 ming 侧未被触达。本实验对"Ming 诊断反馈的修复价值"信息量为零（该价值未被检验，不是被证明）。
2. **污点 API 指引被生成者广泛正确使用**：30/42 个 ming 程序使用 std.unstr/sanitize_path（本报告 grep 计数），0/42 读 env.get；无任何静态诊断记录——语言约束节对污点面的约束在样本内一次通过率高，提示该指引可被模型直接遵循。
3. **TS 腿的静态摩擦集中于工具链配置类错误**（§3.2：TS18047/2802/1259 全部运行时无影响）——若复跑，将 tsc target/esModuleInterop 预置进约束节可分离"语言摩擦"与"配置摩擦"，M2 才有跨语言可比性。
4. **采集器可审计性**：修复轮按轮保留快照（本轮 round-1 已不可复核，MAJOR）；M5 接硬计时、M4 接硬 token 计量（本轮两个辅助指标一缺一疑）。
5. **多样性控制**：温度不可设时需替代策略（提示措辞扰动或显式多样性指令），否则格内 n=3 的方差语义不成立（偏差 1 实证）。
6. **天花板效应与阈值设计**：本任务集对 GLM-5.3-Flash 过易（126/126 终过）。若要检验 H1/H2 的区分力，需要更难的任务面或更大的重复数——这是任务集设计层面的后续项，不是本轮数据的缺陷。

### 8.2 指标计算口径

- **M1** = round-1 行中 first_pass=true 占比，分母 42（每语言）。首过失败仅 a3-ts-r2 一行（first_pass=false, verdict=fail）。
- **M3** = 设计定义"修复循环数"（= 通过轮号 − 1）；matrix.json avg_rounds 为通过轮号口径（1 = 首轮即过）。两种口径 §3.1/§5 并列。
- **M2** = Σ(static_check.errors) + Σ(verify 失败腿数)，按语言除以 42 归一。ming 警告亦全 0（逐行复算）；py_compile 无错误。
- **M4** = tokens.prompt + tokens.completion 合计（自报估算——偏差 4）；ts 合计含 2 个修复轮行。
- **M5** = wall_ms——全 null，未采集。
- **avg_pass_ms**（matrix.json）= 通过腿 verify duration_ms 均值（复算吻合：a1-ming (362+310+261)/3=311；a3-ts 通过腿 (185+180+184)/3=183）——信息性，非预注册 M5。
- 相对差 = |a−b|/min(a,b)，任一值为 0 时只记绝对差并标"不确定"（设计 §3）。
